## Personal development agency

For feature implementation and substantive bug fixes, use the `development-agency` skill in the user's personal skills directory (`~/.claude/skills`). Act as coordinator and explicitly delegate with the Agent tool to the `agency-developer`, `agency-reviewer`, and `agency-tester` subagents. For user interface or user workflow changes, the developer must obtain an `agency-ui-ux` design before implementing the affected UI. Claude Code subagents cannot start other subagents, so the coordinator runs `agency-ui-ux` on the developer's behalf. UI/UX first understands requirements and target platform, designs using adapted Apple Design principles, obtains explicit user design approval through the coordinator, and then returns the approved specification for the developer; the developer alone edits application code.

For every feature, the developer must first investigate and present a brainstorm with necessary questions. Resolve questions and obtain explicit user brainstorm approval before creating the detailed implementation plan. For UI/user workflow work, obtain the separate user-approved UI/UX design after brainstorm approval and before detailed implementation planning. Obtain separate explicit user plan approval before implementation, then report what changed. The reviewer then reviews both the full diff and the whole codebase; present its report and obtain explicit user review approval, with a fix, accept, or defer decision for each finding, before fixes and testing. End every run with the structured final report from the development-agency skill. The coordinator relays proposals and actual user responses; neither silence nor an initial implementation request is approval of these proposals. Read-only investigation and design consultation may proceed while waiting. Follow the role workflow for material revisions and explicit user-directed waivers.

If you are already assigned a scoped agency role, follow that assignment and its role skill instead of restarting the coordinator workflow. Only the coordinator starts agents. Developers, reviewers, testers, and UI/UX advisors do not spawn a second agency.

Use this workflow for development, including future projects. Answer ordinary questions and planning requests directly; honor a user's explicit request to change or skip the workflow. Read project instructions (project CLAUDE.md files) for architecture, commands, and local requirements. If delegation or a required skill is unavailable, disclose the limitation; do not label a single-agent pass as independent review or testing. Never change global settings or permissions to work around unavailable tools.
